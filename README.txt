The comp_info folder contains two folders. App contains the executable and the CSVs which it reads. Source contains the main python script and the dependencies script used to export the app with pycrucible.

Note:
- Ensure comp_info.exe is the the same folder as both CSVs
- Do not rename CSVs

Run:
- Open the comp_info executable.

Update corrosion data:
- Add columns to csv for more compounds, leave empty cells blank.
- Add rows to csv for more materials, leave empty cells blank.
- Simply type in in corresponding cells data to add to the database.
- Restart application to update.
- Update version name in the comp_info_app folder title with date (m.d.yr)
- Log additions to help other users.

Update Antoine parameters:
- Add columns for more compounds with all corresponding rows.
- Restart application to update.
- Update version name in the comp_info_app folder title with date (m.d.yr)
- Log additions to help other users.
